# Phase 3 – Smart Contracts (Samples)

This folder contains **sample contracts + instructions** to demonstrate:

- Ink! (Wasm contracts)
- EVM compatibility (via Revive / EVM interface)

## Ink! (sample)

Recommended tooling:

- `cargo contract` (from `https://github.com/use-ink/cargo-contract`)

## EVM (sample)

Recommended tooling:

- Hardhat + ethers.js

> Note: The repo currently focuses on runtime enablement. For “Phase 3 complete” client proof, you should attach
> deployment transaction hashes and a short report (gas used, call results, etc.) on a running network.
